# TTXSTK · Khối Steinmetz Monte Carlo

Chủ đề 10: Tích phân Monte Carlo trong Hình học — ước lượng thể tích khối Steinmetz
(giao của hai hình trụ x²+y²≤1 và x²+z²≤1, V = 16/3) bằng phân bố đều U(−1, 1) và Luật Yếu Số Lớn.

- `index.html`: trang web mô phỏng tương tác (gieo điểm 3D, lát cắt, thí nghiệm WLLN)
- `monte_carlo_steinmetz.R`: script R gốc (base R, R ≥ 4.0)
- `MonteCarlo_Steinmetz.Rproj`: RStudio project
